# Errors and events

The cases are the same in Swift, Kotlin and TypeScript (trueseal-sync ADR-0028); only the spelling of the type differs.

## Errors

Swift throws an enum, Kotlin a sealed exception class, and TypeScript one `TrueSealError` class whose `code` is a string union, with the fields below as typed extras.

## Events

`onEvent(listener)` accepts any number of listeners. Events raised before the first listener is registered are buffered.

## Delivery issues

`onDeliveryIssue(listener)` is optional, and ignoring it is safe. Every issue stays on the device; nothing is sent back to the sender.
