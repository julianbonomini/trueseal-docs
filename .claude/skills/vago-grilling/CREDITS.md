# Credits

This skill is [Matt Pocock](https://github.com/mattpocock)'s `grilling` skill, from his [`skills`](https://github.com/mattpocock/skills) collection, reproduced almost word for word. One change: where the original dispatches a sub-agent to look up a fact, this copy reads the code itself, since a Vago planning agent has only reading tools and no sub-agents. Vago ships it in the starter so a planning agent can load it in any Project without a user-level install; this file is the attribution a dependency would otherwise have carried.
